# simple-todo-app

A very basic To-Do List web application built with plain HTML, CSS, and JavaScript.

## Files

- `index.html`
- `style.css`
- `script.js`

## How to run

1. Clone or download this repository.
2. Open `/home/runner/work/simple-todo-app/simple-todo-app/index.html` in any web browser.

## Features

- Add new tasks
- Mark tasks as completed with a checkbox
- Delete tasks
